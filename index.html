Unidad 2 • Actividad 4

Despliegue Continuo (CD) y Pruebas


Actividad de Ariel

Demostración práctica del ciclo de pruebas automatizadas, fallos, correcciones y despliegue en GitHub Actions.

¿Para qué sirve esta actividad?

Esta práctica tiene como objetivo comprender la importancia del Despliegue Continuo (Continuous Deployment - CD) y la integración de pruebas automatizadas en los flujos de trabajo (pipelines). Permite comprobar cómo un cambio en el repositorio, ya sea una actualización visual o una corrección de código, se refleja automáticamente en producción solo si los tests pasan con éxito.

Pasos de la Práctica

1

Proyecto base en GitHub 🌐

Selección de un repositorio existente en GitHub configurado con tests automatizados y un pipeline de despliegue.

Repositorio conectado
2

Hacer fallar un test ❌

Modificación intencional de una prueba para forzar un error y comprobar que el sistema de integración detecta fallos y bloquea el despliegue.

Comprobación de errores
3

Modificación del index.html 🔧

Actualización de este archivo web para reflejar el estado actual del proyecto, documentando los cambios realizados.

Interfaz actualizada
4

Corrección y Push Final ✅

Solución de la prueba suspendida, ejecución de un nuevo commit y verificación de que GitHub Actions completa el despliegue con éxito.

Despliegue exitoso
